# 论文材料

## 文件

| 文件或目录 | 内容 |
|---|---|
| `paper.md` | 摘要、引言、相关工作、问题定义、方法、对手下巨人后的完整数据流构造示例（4.9节）、模型选择与维度配置依据（4.10节）、实验设计、参考文献及字段附录 |
| `photo/` | 五张原创方法／流程配图，各提供 PNG 与 SVG；不含伪造性能图 |
| `generate_figures.py` | 配图生成源码，依赖 matplotlib 与 numpy |
| `source_manifest.json` | 写作依据的源码、配置与计划哈希，以及静态网络参数量 |

正文用相对路径引用图片与源码，便于移动整个仓库或发布 Markdown。图中使用英文标签，中文图注解释内容；SVG 将字体转为矢量轮廓，PNG 为220 dpi。SVG可用于论文排版，PNG适合Markdown预览。

第4.9节与图4统一使用 tick 491 对手下巨人、tick 500 我方观测的构造输入，逐步展示公开圣水／卡序更新、九路观测、交叉注意力与循环记忆、等待／选牌概率、每张牌的条件落点热力图、原生命令和后继训练标签。字段数值与默认网络形状经合成状态CPU前向核对；概率表、所选落点与条件式后继均明确作为讲解假设，不构成实战结果或可从标准开局重放的完整轨迹。

## 重新绘图

```bash
python docs/essay/generate_figures.py
```

需要安装 matplotlib 与 numpy 的 Python 环境；论文对应的训练环境不一定安装了 matplotlib。本次使用宿主 base Python 的绘图库生成图片，未修改训练环境依赖。
